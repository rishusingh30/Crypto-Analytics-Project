Crypto Analytics Project

Crypto Analytics Dashboard using Excel, Python, and VBA for cryptocurrency data analysis, visualization, time-based insights, and automated reporting.

View GitHub Repository

Project Overview

This project focuses on cryptocurrency data analysis and visualization using Excel, Python, and VBA. The project analyzes crypto market data, identifies important trends, and presents insights through dashboards and automated reporting.

Project Objectives

  • Analyze cryptocurrency market data.
  • Identify top-performing cryptocurrencies.
  • Analyze trading volume and market trends.
  • Create interactive dashboards and visualizations.
  • Apply time-based analysis using VBA.
  • Generate automated analytical reports.

Tools & Technologies

Microsoft Excel Power Query Pivot Tables Pivot Charts VBA Python Pandas NumPy Matplotlib Seaborn Data Visualization Data Analysis

Excel Dashboard

An Excel-based cryptocurrency analytics dashboard was developed to analyze crypto market performance, trading volume, rankings, and other important metrics.

  • Data cleaning and transformation
  • Pivot Tables and Pivot Charts
  • Interactive dashboard components
  • Crypto ranking analysis
  • Volume-based analysis

VBA Automation

VBA was used to automate dashboard behavior and apply time-based visibility conditions.

  • Time-based dashboard visibility
  • Automated refresh functionality
  • Working-hours condition from 9 AM to 5 PM
  • Dynamic dashboard control

Python Analysis

Python was used for data processing, exploratory data analysis, statistical analysis, and visualization.

  • Pandas for data manipulation
  • NumPy for numerical analysis
  • Matplotlib for visualization
  • Seaborn for statistical visualization
  • Exploratory Data Analysis (EDA)

Key Skills Demonstrated

  • Data Cleaning
  • Data Analysis
  • Data Visualization
  • Dashboard Development
  • Excel Automation
  • Python Programming
  • Statistical Analysis
  • Business Insights
