Crypto Analytics Project
📌 Project Overview

This project focuses on analyzing cryptocurrency market data using Excel, Python, and VBA. The project includes data cleaning, exploratory data analysis, visualization, KPI analysis, and dashboard automation to generate meaningful insights from cryptocurrency data.

The objective is to transform raw cryptocurrency data into an interactive and easy-to-understand analytical dashboard.

🎯 Project Objectives
Analyze cryptocurrency market performance.
Clean and transform raw cryptocurrency data.
Identify top-performing cryptocurrencies based on key metrics.
Analyze trading volume, market capitalization, price, and price changes.
Create meaningful visualizations and KPIs.
Perform task-based analysis using Python.
Develop an interactive Excel dashboard.
Use VBA to automate dashboard visibility and refresh functionality.
Generate actionable insights from cryptocurrency market data.

📈 Excel Dashboard

The Excel dashboard provides an interactive view of cryptocurrency market data.

The dashboard includes analysis related to:

Cryptocurrency prices
24-hour trading volume
Market capitalization
Price changes
Top-performing cryptocurrencies
Comparative performance
Key performance indicators (KPIs)

The dashboard is created using Excel-based analytical and visualization features.

⚙️ VBA Automation

VBA is used to improve dashboard functionality and automate selected dashboard operations.

The VBA implementation includes:

Time-based dashboard visibility
Automated refresh functionality
Dynamic display control
Working-hours validation

For the time-based visibility requirement, the dashboard is designed to be visible during 9:00 AM to 5:00 PM and display a working-hours message outside this period.
